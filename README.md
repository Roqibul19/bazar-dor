
# বাজার দর (Bazar Dor)

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দৈনিক বাজারদর দেখার ওয়েবসাইট।

## Features
- পণ্যের বর্তমান বাজারদর দেখা
- দাম বৃদ্ধি ও হ্রাসের তথ্য দেখা
- ক্যাটাগরি অনুযায়ী পণ্য দেখা
- পণ্যের বিস্তারিত দেখতে লগইন
- Email ও Password দিয়ে Sign Up এবং Sign In
- Responsive Design

## Technologies
- Next.js
- React
- Better Auth
- SQLite
- CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Environment Variables

Create a `.env.local` file and configure the required authentication environment variables.

Do not upload `.env.local` or real secrets to GitHub.
